# Mid-semester report (ACL format)

`main.pdf` is the compiled report. To rebuild:

    latexmk -pdf main.tex

or upload this whole folder to Overleaf (main file: `main.tex`).
`acl.sty` and `acl_natbib.bst` are the official files from
github.com/acl-org/acl-style-files. Fill in the author/institution
placeholders at the top of `main.tex`.

Every number in the report comes from the phase reports in `../docs/`.
